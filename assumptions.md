# Engineering Assumptions

## Project Scope

This project represents a simplified protection engineering case study.

It does not attempt to reproduce a complete utility-grade protection
scheme or manufacturer-specific IED configuration.

The initial model focuses on a single 50 MVA 132/33 kV transformer and
three outgoing 33 kV feeders.

## Modelling Approach

The system will initially use simplified fault current and protection
calculations to demonstrate protection principles.

Further versions may introduce:

- Transformer vector group effects
- CT saturation considerations
- Restricted earth fault protection
- Directional overcurrent protection
- Breaker failure protection
- Auto-reclose schemes
- IEC 61850 SCL concepts
- GOOSE message simulation

## Data

All data used in this project is synthetic and does not represent
actual utility infrastructure, protection settings or operational data.
